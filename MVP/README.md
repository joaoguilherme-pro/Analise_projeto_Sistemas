# UDF NeedVagas - Documentação

Site de documentação (MkDocs Material) do projeto UDF NeedVagas.

## Rodar localmente

```bash
pip install mkdocs-material
mkdocs serve
```

Abra http://127.0.0.1:8000.

## Publicar no GitHub Pages

1. Suba esta pasta para a branch `main` do repositório.
2. Em *Settings > Pages*, escolha a branch `gh-pages` (criada pelo workflow).
3. O site fica em `https://<usuario>.github.io/<repositorio>/`.
